# FORMA / LAB

Персональный кабинет для самостоятельного обучения 3D-дизайну. Статический сайт без регистрации и сервера. Для типографики используется внешний сервис Google Fonts; при его недоступности остаётся системный шрифт. Учебный маршрут основан на `3d_academy_curriculum_v0_1-1.md`.

## Запуск

Из корня проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`. Прямое открытие `index.html` через `file://` не работает из-за ограничений на загрузку модулей.

## Возможности

- Полноэкранная главная с предметной WebGL-сценой (или статичным изображением) и отдельный рабочий раздел «Обучение» (`#/study`). Старые ссылки `#/program` продолжают открывать учебный раздел.

- 7 модулей, 28 недель; полноценное первое занятие, предварительные планы остальных недель из программы.
- Статусы, заметки, сроки, архив работ, фактический прогресс и виртуальная сценарная группа.
- Локальное сохранение в `localStorage`, экспорт и импорт JSON. Данные не синхронизируются между устройствами.
- `python3 scripts/build-curriculum.py` пересобирает `curriculum.json` после изменения учебной программы.

## Визуальные ресурсы и лицензии

- `scene.js` — созданный для этого сайта процедурный рендер куба, металлической сферы и цилиндра. Внешние 3D-модели и видео не используются. При недоступности WebGL, режиме экономии трафика, низком объёме памяти или предпочтении уменьшенного движения показывается исходный кадр.
- `assets/hero-first-lesson.webp` — локальный запасной кадр, существовавший в репозитории до редизайна.
- `assets/people/group-portraits.webp` — локальный набор портретов виртуальных сокурсников, существовавший до редизайна.
- Для двух исходных изображений сведения об авторстве и разрешениях в репозитории не документированы. Их происхождение не следует считать подтверждённой лицензией для стороннего использования.
- `Manrope` подключён через Google Fonts; шрифт поддерживает кириллицу и опубликован под SIL Open Font License 1.1. Файлы шрифта в репозиторий не копируются.

## Публикация на GitHub Pages

Для первичной настройки публикации из `main` откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните. Стандартный адрес: `https://criticsaward.github.io/3D-design-school/`. До публикации он может не работать. Относительные пути и hash-навигация рассчитаны на этот базовый путь.

Личные данные не попадают в репозиторий. Очистка данных сайта в браузере удаляет локальный прогресс; делайте резервные копии экспортом.

## Проверка

Синтаксис: `node --check app.js && node --check chat.js`; данные: `python3 scripts/build-curriculum.py`. Перед выпуском проверьте сценарии на реальном Android Chrome и десктопе: первая неделя → статус и заметка → перезагрузка → календарь → работа → экспорт/импорт.
